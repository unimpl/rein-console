# Provider avatar sources

- Claude: [official Claude favicon](https://claude.ai/favicon.svg).
- Codex: [Lobe Icons Codex SVG](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/codex.svg), under the included MIT license.
- pi: [official pi logo](https://pi.dev/logo-auto.svg), referenced by the [pi repository](https://github.com/earendil-works/pi).

SVG dimensions are normalized for small avatars. The pi viewBox is cropped around its original artwork. Rein uses these marks to identify the simulated CLI provider, without implying affiliation.

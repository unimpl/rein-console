# Rein

## Platform
web

## Stack
React + TypeScript + Vite + @mui/material, as requested.

## Product Purpose
Manage a workspace, projects, requirements and Agent tasks through scoped group conversations and a task panel.

## Capabilities and Constraints
This stage is a runnable frontend with simulated login, project/requirement editing, messages, task execution, CLI output and sessions. No real credentials, model API or execution service. Preferences alone may persist locally. Collapsed navigation keeps context shortcuts and the account avatar, preserving chat width. Project trees scroll independently inside a bounded section. Requirements have hover editing. Agent conversations replace Todo with an illustrative Memory graph. Provider avatars identify Claude, Codex and pi; each Agent has isolated mock basic profile, A2A, local, SKILL and memory-storage settings. Agents can be created from the roster. Header avatars and message authors insert mentions; waiting tasks and messages have explicit attention styling. Agent management is removed; task dependencies are shown directly as dashed arrows on Todo. The Task tab opens with collapsible Spec phases, green completion icons and step progress. Idle tasks can be dragged to reorder or change status; active and waiting Agent sessions lock movement. Results group illustrative documents, design, commits/PR and tests. Chat/Todo toolbar settings remain explicit placeholders.

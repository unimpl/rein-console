# Rein

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
React + TypeScript + Vite + @mui/material, as requested.

## Product Purpose
Manage a workspace, projects, requirements and Agent tasks through scoped group conversations and a task panel.

## Capabilities and Constraints
This stage is a runnable frontend with simulated login, project/requirement editing, messages, task execution, CLI output and sessions. No real credentials, model API or execution service. Preferences alone may persist locally. Collapsed navigation keeps context shortcuts and the account avatar, preserving chat width. Project trees scroll independently inside a bounded section. Requirements have hover editing. Agent conversations replace Todo with an illustrative Memory graph. Provider avatars identify Claude, Codex and pi; each Agent has isolated mock A2A, local, SKILL and memory-storage settings. Agent management is removed; task-flow canvas and chat/Todo toolbar settings remain explicit placeholders.

Resizable desktop panes; usable narrow windows, keyboard navigation, labeled controls and reduced motion.
